Cutroom Publisher

Cutroom Publisher is a personal tool operated by Anthony Thanpoovong. It uploads videos he has edited to his own social media accounts. It is not offered to the public. Last updated November 24, 2026.

Privacy Policy

Cutroom Publisher collects only what it needs to publish: the access tokens each platform grants on sign-in and basic account details such as the account name. These are stored locally on the owner's computer and are never sold, shared or sent to anyone other than the platform being posted to. No data about other people is collected. Access can be revoked at any time from each platform's app settings, which deletes the tool's permission.

YouTube API Services

Cutroom Publisher uses YouTube API Services to upload the owner's own videos. By using it the owner agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Access can be revoked at Google security settings.
